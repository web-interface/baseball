## 1. 한눈에 보기

1. **이벤트 109개**(P 투수 9 · B 타격·주루 9 · F 수비 5 · T 벤치·충돌 8 · W 날씨·환경·관중 10 · R 기록·드라마 8 · C 컨디션·폼 13 · I 부상 7 · M 팀·케미 14 · D 감독·언론 11 · S 시즌·일정 15), 종류: 감지형 31 · 확률형 21 · 상태형 32 · 상황 규칙형 5 · 선택형 15 · 일정형 5.
2. **상호작용 간선 350개**: 부름 209 · 증폭 91 · 막음 25 · 끝냄 25. 부름·증폭만으로 된 순환 78개(길이 5 이하) 모두 감쇠 장치(경기당 횟수·최대 지속·포화·쿨다운·규칙 중 2가지 이상)가 있는 이벤트를 포함함을 자동 검사했다.
3. **이벤트는 확률을 조금, 이야기를 크게 바꾼다.** 효과는 엔진의 '채널'(컨택·파워·선구·적극성·구위·제구·구속·실책·범위·주력)에 더해지고 층 상한을 거친다: 물리층 0.30·tanh(약 ±35%), 심리층 0.113·tanh(약 ±12%), 최종 |합| ≤ 0.47(×0.6~×1.6). 대부분 1~4%.
4. **실측**(2만 경기): 켬/끔 같은 난수 비교에서 팀 득점 4.655 vs 4.670(−0.34%), 홈 승률 차 +0.2%p — 리그 총량은 흔들지 않고 경기의 색을 바꾼다. 최장 연승·연패 평균 6.85·6.55(동전 던지기 기준 6.5) → 연승 폭주 없음.
5. **결정적**: 확률형 이벤트 난수는 카운터 해시 `u01(경기 시드, 스트림, 이벤트 해시, 키)` — 투구·타구 난수와 섞이지 않아 이벤트를 켜고 꺼도 같은 공은 같은 난수다. 같은 경기 재요청 = 같은 이벤트.
6. **지금 엔진 안에서 판정되는 경기 중 이벤트 32개**(흔들림·만루 정면승부·무아지경·어깨 식음·마운드 방문·도루 신경전·사이클 도전·연타석·실책 뒤 위축·동료 감싸기·슈퍼 캐치·위협구 시비·벤치 클리어링·더그아웃 결집·흐름 전환·큰 점수 차·우천 중단·리듬 상실·콜드·강풍·무더위·꽃샘추위·응원 폭발·원정 팬·끝내기·대역전·노히트·퍼펙트·노히트 무산·사이클·탈삼진 쇼·경기 중 부상). 폼 상태 8종(불방망이·슬럼프·분석 당함·구위감·밸런스 붕괴·신인 돌풍·낯선 포지션·혹사)은 엔진이 효과를 읽고, 진입·종료는 서버 몫.
7. **유저 = 감독**: 감독 선택 20종(슬럼프 면담·연패 미팅·노히트 강행·우천 재개 투수·조기 복귀·주전 경쟁·인터뷰 …). 정답은 상황마다 다르고(숨은 원인 + 보이는 단서), 마감까지 고르지 않으면 AI 코치가 같은 규칙으로 고른다. 단서 정답률 = 0.55 + 0.02 × 코치 능력(난이도 연습생 0.55 ~ 레전드 0.95).
8. **러버밴딩 없음**: 유저와 AI 팀에 같은 함수. 연패 팀을 몰래 돕는 보정이 없고, 연패 탈출 보너스는 공개된 분위기 수치로만.
9. **Claude 는 확정된 사실로 글만**: 68개는 템플릿만, 하이라이트급 14개 · 인터뷰 1개 · 리그 소식 묶음 26개만 Claude 후보. 경기 시뮬레이션 요청에서는 부르지 않는다.
10. **연출 예산**: 한 경기 중계 강조 최대 8개(우선순위 순), 유저 선택 팝업 이닝당 1개·주(6경기)당 3개. 예산은 화면에만 — 시뮬레이션 효과는 예산과 무관하게 모두 적용(공정).

## 3. 층·채널·상한 — 엔진 안의 자리

### 3.1 층

| 층 | 이름 | 상한 | 내용 |
|---|---|---|---|
| L0 | 기본 매치업 | — | 진짜 능력치 + 카드·조합 보너스 + 특성 + 구장 + 플래툰 + 홈(경기엔진 3절) |
| L1 | 물리층 | 채널마다 0.30·tanh(x/0.30) (약 ±35%), 부상 배율 ×0.5~×4 | 컨디션·피로·투구 수·감각·통증·낯선 포지션·리듬 상실 |
| L1e | 환경층 | 날씨 물리(비거리 ±12m 등, 날씨 문서) | 12 는 감지만 — env.carry·env.gap 채널은 끔 |
| L2 | 심리층 | 0.113·tanh(x/0.113) (약 ±12%) | 자신감·사기·분위기·폼·흔들림·무아지경·관중·결집·흐름·노히트 긴장·케미 |
| L3 | 전술층 | 작전별 | 번트·히트앤런·전진수비·고의4구·몸쪽 승부 |
| SAN | 최종 안전장치 | 절댓값(물리 + 심리) ≤ 0.47 (ln 1.6) | 어떤 조합도 ×0.6~×1.6 밖으로 못 나감 |

- 예: 원정 투수가 흔들림(제구 −8%) + 응원 폭발(침착 9 이하 제구 −4%) → 심리 합 −0.12 → 0.113·tanh(−1.06) = −0.089 → 단순 합 −12% 가 아니라 **−8.9%**. 겹칠수록 한계 효과가 줄어 '눈덩이'가 없다.

### 3.2 채널 → 엔진 손잡이 (`pitch.ts`, 값 v 당)

| 채널 | 엔진 |
|---|---|
| 컨택 `bat.contact` | 접촉 로짓 +1.3·(컨택 − 상대 구위), 약한 접촉 로짓 −1.5v |
| 파워 `bat.power` | 배트 속도 +10v km/h(+1km/h ≈ 비거리 +1m) |
| 선구 `bat.eye` | 지각 잡음 × e^(−2.0v), 존 밖 스윙 로짓 −1.0v |
| 적극성 `bat.aggr` | 스윙 로짓 +1.2v |
| 구위 `pit.stuff` | 상대 접촉 로짓 −1.3v, 약한 접촉 +1.5v |
| 제구 `pit.control` | 이탈 공 × e^(−2.5v), 위치 σ × e^(−0.8v) |
| 구속 `pit.velo` | +v km/h(층 상한 없이 물리값) |
| 실책 `fld.error` | 모든 실책 확률 × e^v (v 는 ±0.47 안) |
| 범위 `fld.range` · 주력 `run.speed` | 야수 속도 ×(1 + 0.5v)·반응 ×(1 − 0.5v) / 주자 속도 ×(1 + v) |

- 타석 시작에 한 번: 상태 채널(선수 캐시) + 이벤트 채널(그 타석) → 층별 tanh → 합 상한 → 손잡이. 투구마다 다시 계산하지 않는다(CPU).
- 결과 탄성 목표(보정 기준): 컨택 1 → 삼진 −0.8·1루타 +1·홈런 +0.3, 제구 1 → 볼넷 −1·홈런 −0.4 등(12 2.3절 표) — 엔진 변환 계수는 이 탄성의 ±25% 안에 들도록 맞춘다(과제 표 6).

### 3.3 보조 함수 (선수 데이터 읽기)

```
k_c(침착)  = clamp(1.6 − 0.06 × round(composure/5), 0.4, 1.5)   — 흔들림·위축 '확률' 배율
무너짐 폭  = 1.4 − 0.008 × composure                              — 흔들림 '효과 크기' 배율
k_l(리더십) = 1 − 0.015 × max(0, round(leadership/5) − 8)          — 팀 분위기 하락폭(최저 0.82)
k_t(기질)  = clamp(0.4 + 0.06 × (21 − temperament), 0.4, 1.6)     — 충돌 확률 배율
압박 크기 P = clamp((LI − 1)/3, 0, 1) + 상황(만루 0.2 · 언론 비판 0.2), 최대 1.3
큰 경기·압박감·날씨 특성은 선수 데이터 식 한 곳에서만(이중 계산 금지)
```

### 6.5 감쇠 장치의 종류
