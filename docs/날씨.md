## 1. 한눈에 보기

1. **날씨는 '전체 능력치 ±10%'(마구마구 순속·역속)가 아니라 메커니즘별로 들어간다.** 공기 밀도 → 비거리, 바람 → 비거리·옆 휘어짐·변화구 꺾임·낙구 판단, 젖은 공 → 제구·폭투·실책, 젖은 그라운드 → 땅볼 속도·바운드·주루, 더위 → 체력·제구·심판, 추위 → 구속·근육 부상·손 감각, 햇빛 → 타자 시야·뜬공 눈부심, 안개 → 시야·낙구.
2. **진짜 같은 날씨**: 연고 8개 도시(서울·인천·수원·대전·대구·광주·부산·창원)의 3~10월 평년값(기온·일 표준편차·강수량·강수일·계급별 강수·습도·이슬점·일조·풍속·바람장미·안개·황사·폭염·일몰·박명)으로 만든다. 대구 폭염 27일(대프리카), 인천 저녁 해무, 부산 바람, 서울 7월 비 414mm.
3. **생성 = 시즌 체제 → 하루 → 경기 타임라인.** 시즌마다 장마 시작·길이·강도, 태풍(연 3.4개), 여름 더위, 비 많은 해가 정해지고, 하루 날씨는 AR(1) 기온·마르코프 강수·계급별 강수량·계절 바람장미, 경기는 시작 3시간 전 ~ 6시간 뒤 **10분 칸 54개**.
4. **경기 시계로 흐른다.** 투구·플레이·교대 시간이 쌓인 경기 시계로 날씨 칸을 읽으므로 "6회부터 비"가 실제 진행과 맞고, 투수전은 날씨를 덜 겪고 난타전은 더 겪는다.
5. **결정적·분리된 시드**: 날씨 시드 = HMAC(서버 비밀, `wx|리그|시즌|도시|날짜`). 경기 시드와 따로라 예보를 미리 보여 줘도 경기 결과는 계산할 수 없다. 같은 시드 = 같은 날씨.
6. **규정(KBO 를 숫자로)**: 사전 취소(태풍·미세먼지·폭염 체감 35℃·비 3시간 전 6mm/h·1시간 전 3mm/h·그라운드·강풍 15m/s), 경기 중 4mm/h 중단 → 최소 30분 → 1mm/h 미만이면 정비 20분 뒤 재개 → 90분 넘으면 판정(5회 전 노게임 / 그 뒤 콜드·동점 무승부), 폭염 쿨링브레이크(3·7회 뒤 4분), 돔 = 날씨 0.
7. **대표 숫자(보정 실측)**: 기온 5℃ → 35℃ 홈런/타석 .0136 → .0308(1℃당 +1.6%, 목표 +1.8%), 홈런 비거리 10℃당 +5.4ft(목표 5.5), 비 2mm/h → 실책 +25%·폭투 +60%·볼넷 +21%, 시즌 우천 취소 720경기당 51.8(목표 51±15).
8. **선수 숨은 날씨 특성 6종**(내열·내한·우천·주간 시야·바람 판단·박명 시야, 1~20): 그 판정의 날씨 패널티에만 `1 − k(t − 10)` 배. 날씨가 평범하면 효과 0, 판정별 ±5% 상한. 관찰로 16↑·4↓ 만 카드 표식("비의 사나이").
9. **날씨가 전략이 된다**: 비 예보면 에이스를 아끼는 '도박', 외야로 부는 바람이면 땅볼 투수·거포, 안으로 부는 바람이면 발·작전, 젖은 그라운드면 땅볼 유도·도루 자제, 폭염이면 투구 수 −10·포수 휴식, 맑은 낮이면 햇빛 쪽 외야에 주간 시야 좋은 수비수.
10. **예보는 틀릴 수 있다**: '그림자 앙상블'(진짜 날씨와 상관 ρ 인 가짜 날씨 8개)로 D-1 강수 적중(CSI) 0.42~0.47 — 기상청 실제(0.41~0.45) 수준. (지금 코드 없음 → 9절 과제.)
11. **바람(17 심사에서 복원)**: 보정이 0.2배로 깎았던 바람 노출을 1.0 으로 되돌렸다(홈런 총량은 `air.offset` −1.8 로 유지). 노출 0.4 구장에서 외야로 4.5m/s → 홈런 +35%(목표 +40%±10), 안으로 −41%(목표 −13%±6 보다 큼 → 11절 과제 1). 시즌 실측 득점/경기: 외야로 2.5m/s↑ 10.5 · 약함 9.5 · 안으로 2.5m/s↑ 8.4.
12. 비거리 지수(감독에게 보여 줄 한 숫자) = 0.18·(T−20) − 0.04·(P−1013) + 0.005·(RH−60) + 2.2·외야로 부는 유효 바람(m), 홈런 변화 = e^(0.095×지수) − 1.

| 한 번만 계산 | ① **물리층**(모든 선수 공통: 공기 밀도·바람·젖은 공·그라운드·태양·시정·규정)은 엔진 물리 계산 안에서 한 번. ② **반응층**(제구·컨택·체력·부상·시야)은 날씨 강도 × 선수 날씨 특성 배율로 그 판정에만. 이벤트(12)는 날씨를 '감지'만 하고 효과를 다시 곱하지 않는다. |

| 공정 | 같은 날씨를 두 팀이 똑같이 겪는다(홈 팀만의 날씨 보너스 없음 — 다만 구장 숙련은 경험으로 생김, 과제). |
| 투명 | 경기 전 예보 화면, 경기 중 날씨 로그(테이프 `wx`), 원인 표시 "↳ 바람 +6.1m(담장 2.3m 차)". Claude 중계 글은 날씨 로그 값만 인용한다. |

## 3. 생성 모델 (`weather.ts`)

### 3.1 시즌 체제 — `seasonRegime(seed, year)` (시즌 시작 때 1번)

| 값 | 생성 |
|---|---|
| 봄 기온 이상 / 여름 더위 이상 | N(0, 0.7℃) / N(0, 1.2℃), + 기후 추세 +0.6℃(2027 가정, 0 이면 평년 그대로) |
| 비 많은 해 | 로그정규(σ 0.15) → 강수확률 × √값 |
| 장마 | 중부·남부 평년 시작일 + N(0, 6일)(−10~+9), 길이 N(31.5, 8)일(14~54), 강도 로그정규(σ 0.35) |
| 태풍 | 포아송(3.4개), 달 가중 6월 .3 · 7월 1 · 8월 1.2 · 9월 .8 · 10월 .1, 중부 도달 55%, 강도 0.6~1.4 |
| 황사 계수 | 0.6 × 로그정규(0.4) |

### 3.2 하루 — `dailyWeather(도시, 날짜, 체제, 어제 상태, seed)` (도시마다 날짜 순서대로)

```
그날 평년값 = 이번 달과 앞뒤 달을 15일 기준 직선 보간
비 올까: 1차 마르코프  π = 강수일수/일수(태풍 몫 빼고) × √(비 많은 해), 장마 안 ×1.25(상한 0.62)·밖은 달 합계 보존
         p(비|어제 비) = π + r(1−π), p(비|어제 맑음) = π(1−r), r = 3~5월 .30 · 6월 .35 · 7월 .45 · 8월 .35 · 9~10월 .30
얼마나: 계급(0.1~1 / 1~10 / 10~30 / 30+ mm) 평년 비율로 고르고 계급 안 로그 균등, 30mm 위는 지수 꼬리, 장마 ×강도, 태풍 날은 30 + 90·강도·U mm
기온: 일최고·일최저 이상값 AR(1)(φ 0.70 / 0.65, 서로 상관 0.6) × 평년 표준편차 × 도시 배율(서울 .95 … 대구 1.32 · 창원 1.30)
      + 비 온 날 최고 −3℃·최저 +0.8℃(맑은 날 반대 보정으로 평균 보존) + 체제 이상
이슬점 = 평년 + 이상×0.8 + (비 +2 / −0.8) + 2·N, 최저기온 + 1 이하
바람: 평균 풍속 와이블(k=2, 평년 평균), 방향 = 계절(봄·여름·가을) 16방위 바람장미에서
하늘: 맑음 확률 = clamp(1.35 × 일조율 − 0.12, 0.05, 0.9) → 맑음 / 구름 조금 / 흐림, 비 오면 흐림·비
안개(저녁): 비 없고 바람 < 3m/s, 평년 안개일 × (해안 / 내륙 계수) × 3
미세먼지 경보: 달별 확률 × (황사 날 배율)
시간별 비: 강도 I0·mm^지수로 몇 시간 올지 → 시작 시각 가중(장마 / 여름 소나기 / 그 밖) → 1~2 덩어리에 나눔
```

### 3.3 경기 타임라인 — `gameTimeline(오늘, 어제, 구장, 시작 시각, seed)` → 10분 칸 54개(시작 −3시간 ~ +6시간)

```
기온(시각) = 파튼-로건 단순형: 해 뜬 뒤 사인 상승 → 14:30 최고 → 일몰까지 선형 하강(일교차의 25%) → 밤 지수 감쇠(k 2.2)
습도 = 이슬점·기온에서 계산 · 체감온도 = 20℃↑ 기상청 여름식(습구온도), 10℃↓·바람 1.3m/s↑ 풍속 냉각
바람: 방향 랜덤워크(칸마다 ±9°), 속도 AR(1)(0.8) 평균 = 하루 평균 × (12~17시 오후 배율 / 18시~ 저녁 배율), 돌풍 = 속도 × (돌풍 계수 + 0.15·N)
비: 그 시각 강수 × (0.6 + 0.8·U) mm/h → 단계 0 (<0.1) · 1 (0.1~1) · 2 (1~4) · 3 (≥4)
그라운드 물통: 어제 12시 이후 + 오늘 비 − 배수(A 6 · B 4 · C 2.5 mm/h) 누적 → 0 마름(<0.5) · 1 촉촉(<3) · 2 젖음(<8) · 3 물웅덩이
태양: NOAA 근사(위도·경도·날짜·시각) → 고도·방위
시정: 안개 날 일몰 뒤 해무 구장(인천·부산) 0.3~1.5km, 폭우 3km, 그 밖 15km
돔: 23℃ · 습도 50% · 무풍 · 비 0 · 흐림 · 해 없음(효과 0)
```
- 비용: 하루 0.05ms, 타임라인 경기당 0.2ms 미만. 서버는 도시별 '날씨 일지'(어제 상태)를 하루 1행으로 캐시해 처음부터 다시 굴리지 않는다.

## 8. 예보·화면·감독 판단

### 8.1 예보 — 그림자 앙상블 (설계 확정, 코드 과제)

```
진짜 날씨를 만든 잠재 정규난수 z 마다 z' = ρ·z + √(1−ρ²)·ε 를 K = 8 벌 → 같은 생성기에 넣음
예보값 = 8벌 평균, 강수확률 = 비 온 벌 비율
리드타임별 ρ: D-3 0.50 · D-1 0.72 · 당일 09시 0.82 · 시작 3시간 전 0.92 · 1시간 전 0.96 ('기상 분석' 스태프 최대 +0.05)
검증(이변량 정규 20만 회): D-1 ρ 0.72 → 강수 CSI 약 0.42~0.47 (기상청 2021~2025 0.41~0.45)
```
- 예보 난수 ε 는 날씨 시드의 별도 키(`wxfc|…|리드타임`)로 → 예보도 결정적, 같은 시각에 다시 보면 같은 예보.

### 8.2 경기 전 화면

강수확률 · 17~22시 시간대별 비 막대 · 기온·체감 · 구장 그림 위 바람 화살표 · **비거리 지수**(+m, 홈런 %) · 그라운드 상태 예상 · 취소 가능성(낮음/보통/높음) · "오늘 주심: 낮은 공에 후함".

```
비거리 지수(m) = 0.18·(T−20) − 0.04·(P−1013) + 0.005·(RH−60) + 2.2·w_out,  w_out = 도시 풍속 × 구장 상층 노출 × cos(바람 가는 방향 − 홈→중견 방위)
홈런 변화 = e^(0.095 × 지수) − 1
예: 4월 저녁 10℃ 무풍 −1.8m(홈런 −16%) · 8월 저녁 30℃ 무풍 +1.8m(+19%) · 30℃ + 외야로 5m/s(노출 0.4) +6.2m(+80%) · 15℃ + 안으로 6m/s(노출 0.5) −7.5m(−51%)
```
- 화면 숫자와 엔진이 같아야 한다 → `carryIndex()` 와 엔진 비행 모두 구장 노출 계수를 그대로 쓴다(17 심사에서 엔진의 `air.expo` 를 0.2 → 1.0 으로 되돌림) — 지수와 엔진 실제 값이 같다.

- AI 코치 규칙 14개(`16_weather.json strategy_ai.rules`)가 위 판단의 기본값이자 '추천' 말풍선이다(문장은 템플릿/Claude, 판단은 코드). **지금 엔진 AI 는 재개 뒤 선발 교체만 날씨를 본다** → 나머지는 서버의 경기 전 라인업·전술 자동 설정(과제 6)으로 넣는다.
