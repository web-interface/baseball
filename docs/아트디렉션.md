### 0.3 조사에서 가져온 원리 (코드·이미지는 가져오지 않음)

- **실물 카드의 패럴렐·리프랙터**: 같은 사진의 카드를 테·포일 색만 바꿔 여러 희소도로 낸다. 기울이면 무지개 반사, 번호가 적을수록 귀함, 끝판은 '1/1'. → 등급 = 패럴렐, 특별 선수 = 1/1.
- **고등급 팩 연출(워크아웃)**: 등급을 먼저 빛으로 암시하고 정체는 단계적으로(엠블럼 → 포지션 → 카드). → 9절 모듈.
- **가챠 연출 문법**: 낮은 등급은 차갑고 짧게, 최고만 길게, 매번 길면 다 건너뛴다(연출 배급).
- **CSS 홀로 기법**: 그라디언트 여러 겹 + 블렌드 + 포인터 위치 변수 + 마스크. 휴대폰 GPU 비용이 커서 큰 카드 1~2장에만.
- **문장형 엠블럼**: 틀(대칭) + 상징 하나 + 2~3색. 상징을 지운 미니멀 리브랜드는 팬 반발을 산다 → 동물·지역 상징은 남긴다.

## 1. 테마 3종과 색

### 1.1 모든 테마 공통

- **빛 방향 고정**: 키 라이트 = 왼쪽 위 45°(조명탑), 림 라이트 = 오른쪽 위 뒤, 그림자 = 아래·오른쪽으로 짧고 흐릿하게. 하드 섀도 금지.
- **한 화면에 주인공 하나**(카드 한 장 또는 큰 숫자 하나). 나머지는 물러난다.
- **카드는 테마의 영향을 적게 받는 '물건'**이다. 테마가 바꾸는 것은 화면(바탕·글꼴 표정·모서리·질감)과 카드의 **표현 방식** 하나뿐: night·broadcast = `foil`(금속·포일 빛), classic = `print`(인쇄물, 4.10).
- 구현: `<html data-theme="night | broadcast | classic">`, 토큰은 `web/src/theme/tokens.css`(이 절의 값과 같다). 선택은 `localStorage['bb.theme']`(읽기·쓰기 try/catch, 없으면 night), 주소 `?theme=classic` 으로도 바뀐다, `<meta name="theme-color">` 를 테마의 `--header-bg` 로 바꾼다. 요소에 `data-theme` 를 붙이면 그 안만 그 테마(설정 화면 미리보기).

### 1.4 색 역할 (색을 아끼는 법)

- `--accent` = 주 버튼·선택·포커스. `--gold` = 재화와 '사기·뽑기·강화' 버튼에만. `--volt` = 완성·최고·형광·폭발에만, 한 화면 2곳까지. 빨강 = 오류·끊김·위험.
- **등급 색** = 카드 안과 등급 이름 글자에만(버튼·탭·바탕에 쓰지 않음). **구단 색** = 카드 이름 띠·엠블럼·팀컬러 막대·홈 큰 장면에만.
- 색만으로 정보를 주지 않는다: 등급은 테 두께·무늬·영문 이름, 케미는 굵기, 구단은 엠블럼과 이름을 항상 같이.

## 2. 글꼴

### 2.1 고른 글꼴 (모두 npm 패키지, OFL-1.1, 런타임 CDN 없음 — `web/src/theme/fonts.ts`)

## 3. 화면 틀 (모든 화면 공통)

- 휴대폰 360~430px 이 기본, 좌우 여백 16(`--gutter`), 본문 칸 최대 600(`--col`) 가운데. 넓은 화면은 칸을 늘리지 않고 양옆을 비운다(카드 격자만 열 수를 늘림).
- **4px 격자**(`--sp-*` 2·4·8·12·16·20·24·32·40·56). 정렬 어긋남 1px 도 허용하지 않는다.
- 위쪽: 헤더 52(`--header-h`) + 위쪽 메뉴 40(`--menu-h`, 글자 탭 가로 스크롤: 홈 · 영입 · 라인업 · 카드 · 설정, 2차에 경기·대전·도감). **아래 탭바·아래 고정 버튼 없음**(웹사이트, 앱 흉내 금지). 안전영역 `env(safe-area-inset-*)` 반영.
- 깊이: 면 3단(`--surface` 1~3) + 그림자 2종(`--shadow-1` 선, `--shadow-2` 떠 있는 것) + 시트 그림자. 유리·흐림(backdrop-filter) 없음.
- 상자를 아낀다: 목록은 행 구분선, 요약은 큰 숫자와 여백, 상자는 '눌러서 무엇이 되는 것'에만. 같은 틀 반복 금지.

## 4. 카드

### 4.1 원칙 — 실물 트레이딩 카드 (사용자 41번)

1. **그림이 카드를 채운다.** 선수(캐릭터 생성기, 5절)가 결정적 순간의 자세로 카드 높이의 85% 이상을 차지하고, 뒤는 그 구단 홈구장이 흐릿하게(5.6).
2. **비스듬히 잘린 구단색 이름 띠**가 아래를 가로지른다: 영문 성 대문자 + 한글 이름 + 등번호, 왼쪽 끝에 구단 엠블럼.
3. **리그 마크**(한별 리그, 6.8)가 작게 들어간다 — 실물 카드의 제조사 로고 자리.
4. **등급 = 패럴렐**: 같은 구성·같은 그림에 테·포일·무늬만 다르다(4.4). 등급을 알리는 것은 테와 포일과 맨 아래 영문 등급 이름이지 그림이 아니다.
5. 앞면은 '보는 면'(그림·이름·OVR·포지션·연도·강화·레벨), **능력치와 기록은 뒷면**(4.8)과 상세 화면.
6. 낮은 등급도 정성: 노멀도 조명·림 라이트·정렬은 최고 등급과 같은 품질. 차이는 테와 포일뿐.

### 4.2 비율과 층

- 비율 5:7(실물 2.5×3.5인치). 기준 크기 **L 250×350**, 모든 좌표는 L 기준(다른 크기는 4.7).
- 카드 모서리 반지름 = 카드 폭 × 0.048(L 12 · XL 14 · M 8 · S 4 · Mini 3). 테 두께 `b` 는 등급마다(4.4).

층(아래 → 위):

1. 테(frame) — 등급 재질 그라디언트 + 테 무늬(`::before`)
2. 그림 창 = 테 안쪽 (250−2b)×(350−2b), 모서리 max(2, 12−b)
3. 배경: 흐릿한 경기장(5.6) → 등급 배경 처리(4.4의 '배경') → 포일 층(4.5, 그림 **뒤**에만)
4. 선수 그림(5절) + 림 라이트
5. 앞쪽 효과: 시그니처 친필 서명 · 엘리트 이상 반짝임
6. 위쪽 어둠(왼쪽 위 OVR 가독용 radial) · 아래쪽 이름 띠 · 아래 띠(레벨·등급 이름)
7. 정보: OVR · 포지션 · 연도 도장 · 강화판 · 배지 · 엠블럼 · 이름 · 등번호 · 리그 마크
8. 빛: 시트(sheen) 띠 · (시그니처) 홀로 링·글레어 · 테 안쪽 1px 키라인
9. 카드 그림자 `0 18px 40px -18px rgba(0,0,0,.85)`(classic 은 `0 10px 24px -14px rgba(29,30,33,.35)`)

### 4.9 상세(XL)와 기울이기

- 탭(또는 '뒷면' 버튼) = 뒤집기(rotateY 180°, 420ms). 뒷면은 4.8 ②.
- 카드 아래에는 상세 능력치 표(13.4: rem 단위로 커짐).

### 4.10 클래식 테마의 '인쇄 카드' (사용자 32번)

카드를 금속·빛이 아니라 **인쇄물**로 그린다. 같은 카드 데이터, 다른 표현.

| 요소 | 규칙 |
|---|---|
| 잉크 | 먹(#1D1E21) + 구단 별색 1 + 종이색, 여기에 등급 잉크 1(1.7 classic 열)까지 — **최대 4색**. 그라디언트 없음 |
| 선수 그림 | 캐릭터 생성기 출력을 **2도 인쇄**로: 모든 면을 먹 농도 5단(0·25·50·75·100%)으로 바꾸고 유니폼 색만 별색. 그 위에 망점(`--halftone` 4px, multiply) |
| 판 어긋남 | 별색 판을 먹 판보다 (0.7px, 0.5px) 밀어 찍음(`--misreg`) — 1px 넘지 않게 |
| 용지 | `--texture` 섬유 결, 테 바깥 0.5px 먹 선(재단선 느낌) |
| 테 | 종이색 여백 테(b 그대로) + 안쪽에 등급 잉크로 **선 무늬**: 노멀 가는 선 1줄 · 스페셜 2줄 · 레어 굵은+가는 2줄 · 엘리트 점선 + 선 · 레전드 금박 띠 · FR 금박 + 별색 · 블랙 먹 전면 · 시그니처 홀로 포일 띠 · 수상 금박 + 장식 · 특별 선수 민트 별색 + `1/1` 번호 도장 |
| 금박 | **레전드 이상·수상 카드에만**(레전드·엘리트·FR·블랙·시그니처·MVP·GG·TH). 금박은 포일이라 상세에서 기울이면 반짝이는 유일한 부분 |
| 이름 띠 | 별색 띠 + 종이색 글자(망점 없음), 띠 윗변 사선 그대로 |
| 숫자 | OVR = Big Shoulders Display 800(점수판 숫자), 레벨·연도 = Barlow |
| 움직임 | 없음(종이는 빛나지 않는다) — 공개 연출은 '잉크가 번져 찍히는' 600ms(그림 opacity 0→1 + 망점 크기 0→1) |
| 뒷면 | 4.8 ② 그대로(원래 종이) + 연필 손글씨 메모(Nanum Pen Script, 기록지 기호 `6-4-3` 등은 카드 뒤 기록 줄에만) |

금지: 크림색 + 금 그라디언트로 카드 전체 덮기, 세리프 남발, 의미 없는 금박 모서리, 기울인 스티커·티켓·우표 모양.

## 5. 선수 그림 — 캐릭터 생성기

### 5.1 방식과 결정

- **모든 카드 = 같은 체계의 코드 생성 그림**: `web/src/art/character`(외부 라이브러리 없음, SVG 문자열). 화면은 입구 `art/PlayerArt.tsx`(`portrait · full · mini`)로만 그린다.
  - `makeAppearance(spec)` — 시드(인물 id = `CardDef.look`) → 얼굴·피부·머리·수염·체격. **같은 인물은 모든 카드에서 같은 얼굴**(나이만 그 카드 시즌 나이).
  - `makeKit(spec, ap, team, 'home')` — 구단 색 → 유니폼·장비. `team` 은 `shared` 의 `CLUBS` 에서 만든다(`kit.ts` 의 임시 `TEAMS` 4개는 미리보기 전용으로 남기고 게임 화면에서 쓰지 않는다).
  - `renderPortrait(ap, kit, { width })` — 초상(작은 카드), `figureSvg(ap, kit, pose)` · `live.ts`·`motion*.ts` — 전신 동작(큰 카드·폼 보기).
- '실사 사진 같은' 느낌은 **그리는 법**으로 낸다(사용자 41번): 피부·천 3단 명암(base · shade · deep) + 반사광(light) + 림 라이트(rim) 1.5px, 근육 볼륨과 천 주름 2~3줄, 발밑 접촉 그늘, 망원 렌즈처럼 납작한 원근(낮은 카메라 높이), 뒤 경기장은 초점 밖(5.6). 검은 외곽선 만화체 금지.
- **실사풍 생성 이미지(Workers AI 등)는 1차에 쓰지 않는다.** 바탕화면 '실사카드' 시제품이 아래를 모두 넘을 때만 2차에 다시 판단: ① 한 인물의 여러 카드에서 같은 얼굴 ② 실존 선수와 닮지 않음(사람 눈 검수) ③ 무료 사용량 안 + 다른 사이트 몫 침범 없음 — 카드 목록 1,042장을 **한 번만 미리** 만들어 정적 WebP 로 Pages 에(실행 중 생성 금지) ④ 유저마다 새로 만드는 **특별 선수도 같은 품질**. ④를 못 넘으면 쓰지 않는다 — 카드마다 그림 체계가 다르면 원작 '석고상' 문제가 다시 생긴다.

### 5.2 자세 — 카드 한 장 = 결정적 순간 하나

큰 카드(L·XL·M)의 전신 자세는 (세트, 포지션·보직, 플레이스타일)로 정하고, 같은 줄 안에서는 `hash(카드 id)` 로 하나를 고른다 → 같은 인물의 다른 카드는 다른 자세(원작 「라이브는 사진도 다름」).

| 대상 | 기본 자세 후보 |
|---|---|
| 선발·불펜 | 공을 놓기 직전(팔 각도 = 그 선수 투구 폼) · 다리를 든 정점 |
| 마무리 | 공을 놓기 직전 · 마지막 공 뒤 글러브 주먹(수상·블랙·시그니처) |
| 포수 | 미트를 내민 낮은 자세 · 마스크를 벗고 일어서며 송구 |
| 1루 | 다리를 찢어 받는 포구 |
| 2루·유격 | 점프 송구 · 다이빙 캐치 |
| 3루 | 백핸드 포구 후 송구 |
| 외야 | 펜스 앞 점프 캐치 · 홈 송구 |
| 지명·타자 공통 | 임팩트 직후(타격 폼 반영) · 큰 팔로스루 |

| 플레이스타일(+5) | 바뀌는 자세 |
|---|---|
| 교타자 | 밀어 치는 짧은 팔로스루, 시선은 타구 |
| 거포 | 두 손 큰 팔로스루, 고개 들어 담장 너머 봄 |
| 호타준족 | 1루로 뛰어나가는 첫 걸음(배트를 놓는 순간) |
| 수비 달인 | 다이빙 캐치 |
| 리드오프 | 도루 출발(몸이 2루 쪽으로 기움) |
| 파이어볼러 | 높은 팔 끝 릴리스, 이를 악문 얼굴 |
| 기교파 | 손목을 꺾는 변화구 릴리스 |
| 이닝이터 | 세트 포지션에서 포수를 응시 |
| 불펜 에이스 | 경기를 끝낸 뒤 글러브 주먹 |

- 세트별 덧붙임: 레전드 = 그 시대 유니폼(5.5) · FR = 홈 유니폼 + 관중 쪽으로 모자 들어 인사(후보에 추가) · 블랙 = 대체 검정 유니폼 · 시그니처 = 가장 극적인 후보 우선 · 수상 = 기쁨(표정 `smile`) · 특별 선수 = 창단 때 고른 폼의 결정적 순간.
- 자세 키 프레임은 폼 애니메이션(`motion.ts`·`motionPitch.ts`)의 한 프레임을 쓴다 — 경기 화면(2차)의 동작과 카드 그림이 같은 폼.

### 5.3 얼굴·체격 (`appearance.ts`·`build.ts`)

- 출신 묶음 `origin`(KR · JP · TW · US · USB · LATAM · AU)이 외모 분포를 고른다. 카드 목록 생성기가 고향·국적으로 정한다(세계관 이름 규칙과 같이).
- 체격 = 키·몸무게(BMI) → lean · athletic · power · heavy · lanky. 거포는 power·heavy 쪽, 리드오프·중견수는 lean·athletic 쪽이 많게(생성기 아키타입).
- 나이: 33세부터 이마선이 조금씩 올라가고 35세부터 흰머리 섞임, 이마 주름·팔자 주름이 나이에 따라. 레전드 카드는 **황금기 시절 나이**로 그린다.
- 표정: 시즌 카드 `determined` 위주, 수상 `smile`, 블랙 `neutral`(강한 눈빛). 안경·선글라스(위로 올린 것 포함)·아이블랙은 낮은 확률.
- 다양성 규칙: 과장·희화화 금지, 피부·머리 색은 출신 분포 그대로, 특정 실존 선수를 떠올리게 하는 외모 조합(유명한 머리 모양 + 수염 + 등번호 같은 묶음)을 일부러 만들지 않는다.
- 겹침 검사: 카드 목록 1,042장의 인물 얼굴 특징값(얼굴형·눈·코·입·머리·수염 정규화 벡터)에서 너무 가까운 쌍 0(목록 생성 검사에 포함).

| 팔 각도 | 오버핸드 · 스리쿼터 · 사이드암 · 잠수함(언더) |
| 시작 | 와인드업 · 세트 |
| 다리 | 높게 · 보통 · 슬라이드 스텝 |
| 템포 · 공 숨김 · 팔 동작 · 마무리 | 빠름/보통/느림 · 좋음/보통/드러남 · 길게/짧게 · 균형/옆으로 쓰러짐/뛰어오름, 크로스파이어 |

| 타격 폼 | 값 |
|---|---|
| 스탠스 | 스퀘어 · 오픈 · 클로즈드 |
| 다리 | 레그킥 · 작은 레그킥 · 토탭 · 노스트라이드 |

- 카드는 그 폼의 결정적 프레임, 선수 상세의 '폼 보기'는 같은 폼을 1.2초 반복 재생(`live.ts`, 움직임 줄이기면 정지 프레임 3장).
- 특별 선수는 창단 때 고른 값(기획서 2.5)을 그대로 쓴다. 카드 뒷면에 폼 이름(`스리쿼터 · 레그킥`).

### 5.5 유니폼·장비 (`kit.ts`)

- 홈 유니폼이 기본. 색 = 구단 주색·보조색·강조색(6.5 표).
- **가슴 글자 = 한글 짧은 이름(독수리스) 또는 영문 지역명(DAEJEON)만.** 구단 별명을 영어로 옮긴 글자는 쓰지 않는다 — 실제 구단 이름과 같아진다.
- **모자 = 엠블럼 상징 하나(S 상세도), 글자 없음.**
- 등번호 = `CardDef.number`. 바지 줄·양말·언더셔츠·팔 토시·손목 밴드·배팅 장갑·헬멧 무광/유광은 시드로 섞는다.
- 시대 유니폼(레전드 카드 — 황금기 연도로):

| 시대 | 모양 |
|---|---|
| 1985~1989 | 풀오버 상의, 소매 끝 굵은 띠 2줄, 넓은 깃, 둥근 글자, 바지 옆 굵은 줄 |
| 1990~1999 | 핀스트라이프(홈), 이중 테두리 글자, 깊은 모자 |
| 2000~2009 | 민소매 조끼형 상의 + 구단색 언더셔츠, 가는 소매 띠 |
| 2010~ | 지금 유니폼 |

- 블랙 카드 = 검정 대체 유니폼(글자·번호 = 구단 강조색). FR = 홈 유니폼 + 소매에 금색 가는 띠 한 줄.
- 장비(2차, 기획서 7.6)는 그림에 실제로 보인다: 배트 색, 글러브 모양·색, 스파이크 색. 로고·브랜드 글자 없음.

### 5.6 배경 — 흐릿한 경기장

카드 그림 창 뒤는 **그 카드 구단 홈구장**(세계관)의 밤. 사진 대신 부드러운 도형으로 '초점 밖' 느낌을 그린다(큰 면에 CSS `filter: blur` 를 걸지 않는다 — 미리 흐린 모양의 그라디언트로).

| 층(뒤 → 앞) | 그리는 법 |
|---|---|
| 하늘 | night `#03060C → #0B1830` 세로 그라디언트 |
| 조명 보케 | 지름 24~60px 원 5~7개, `radial-gradient(#FFF4DE 0, transparent 70%)` 불투명 .25~.6, 왼쪽 위에 몰리게(키 라이트와 같은 쪽) |
| 관중석 | 어두운 띠 + 망점 군중(구단 주색·보조색 10%) |
| 외야 담장 | 구단 보조색 띠 + 흐린 거리 숫자(Barlow, 흰 10%) |
| 잔디 | `--field-grass` 두 줄무늬, 아래로 갈수록 선명 |
| 구장 특색(한 가지만) | 아래 표 |

| 구장 | 특색 |
|---|---|
| 갑천 볼파크(독수리스) | 오른쪽에 높은 '갑천 벽' |
| 영산 필드(호랑이즈) | 외야 너머 강 수면 반사, 1루 쪽 군중 점이 빽빽 |
| 신천 볼파크(사자즈) | 지평선 위 따뜻한 열기(주황 아지랑이 띠) |
| 광안 스타디움(거인츠) | 외야 너머 바다와 대교 불빛 줄, 높은 담장 |
| 한강 볼파크(곰스·쌍둥이스) | 큰 전광판 — 곰스 홈이면 남색·은, 쌍둥이스 홈이면 와인빛 조명 |
| 노을 돔(영웅즈) | 하늘 대신 돔 지붕 갈비 곡선 + 노을빛 테두리 |
| 월미 필드(상륙스) | 항구 크레인 실루엣과 바다 |
| 합포 필드(공룡스) | 계단식 외야 관중석 |
| 팔달 스타디움(마법사즈) | 성곽 모양 외야 담장 + 조명 쇼 빛줄기 |

- 등급 처리(4.4)가 이 위에 덮인다: 레전드 = 필름 톤, 블랙 = 거의 검정, 특별 선수 = 해 질 녘.
- classic(print): 같은 구성을 먹 선 스케치 + 망점으로(기록지 귀퉁이에 연필로 그린 구장 같은 느낌).

### 5.7 크기별 그리기와 저장

| 표시 높이 | 그림 |
|---|---|
| 160px 이상(L·XL·공개) | 전신 동작 + 효과 + 림 + 그늘 + 경기장 특색 |
| 100~159(M) | 전신 동작 + 림(효과·특색 생략) |
| 99 이하(S·Mini·Row·Token·30장 격자) | 초상(`renderPortrait`) + 림, 배경은 구단색 그라디언트만 |

- 메모 키 = `카드 id | 크기 단계 | foil·print | 스타일`, LRU 300개. 30장 격자는 초상만 쓰므로 한 팩 30장을 한 프레임에 그려도 된다.
- 특별 선수 미리보기(창단)는 입력이 바뀔 때마다 다시 그림 — 150ms 디바운스.

### 5.9 선수 그림 합격선 (총괄 점검 추가 — '짜치지 않게'의 가장 큰 위험)

### 7.2 해부도 (2:3 — 상점 150×225, 개봉 화면 220×330)

- 외곽: 사각 + **위·아래 톱니 봉합**(주기 7.5, 깊이 6). SVG `<path>` + `clipPath` 로 모든 층을 자름. 1px 흰 35% 외곽선.
- 층(아래 → 위): 포일 바탕 → 구김 면(큰 삼각형 3개, 흰 5%) → 세로 반사 띠(x 23%~45%, 흰 0 → 38% → 0) → 위 봉합 띠(높이 24, 검정 18% + 세로 골 1px/5px 흰 12%) + 그 아래 1px 흰 35% → 절취선(y 30, 3-3 점선) → 아래 봉합 띠(22) → 가운데 리그 마크 60px → 팩 이름(Wanted Sans 900 20px) → 영문 이름(Barlow 700 11px, 자간 .2em, 70%: `STANDARD` `PREMIUM` `SPECIAL` `LEGEND`) → 안내 태그(80×18, 모서리 3, 검정 28%, Pretendard 700 10px: `레어 이상 1장` 등 보장 문구).
- 오른쪽 위 봉합 띠에 작은 V 절개(찢는 곳 힌트). 팩 아래 텍스트 버튼 **'확률 보기'**(→ 확률 공개 화면).

### 7.3 재질 표현

- 포일 반사: 상점에서 **선택된 팩만** 반사 띠가 4초마다 1번 지나감(1200ms). 나머지는 정지.
- 레전드팩 홀로 띠는 선택 시 `background-position` 이동. classic 테마: 포장도 인쇄물 — 먹 + 별색 + 금박(프리미엄·레전드만), 반사 없음.

### 7.4 찢기 연출

1. 개봉 화면 가운데 팩, 위 봉합 띠에 '밀어서 열기' 힌트(흰 60% 화살표가 1.6s 마다 왼쪽 → 오른쪽).
2. 손가락으로 띠를 오른쪽으로 끌기: 진행도 p = 끈 거리 ÷ 팩 너비. 위 띠(절취선 위 30px)를 별도 조각으로 `rotate(−14°×p)` · `translateY(−18px×p)`, 절취선 틈에서 빛(흰 → 팩 신호색, opacity p×.8).
3. 놓을 때 p ≥ .6 이면 220ms 로 끝까지, 아니면 260ms 되돌아감(`cubic-bezier(.34,1.56,.64,1)`).
4. 완료: 위 띠가 (−30, −80) 으로 −28° 돌며 날아감(380ms) → 입구 빛 기둥 scaleY 0 → 1(240ms) → 카드 30장이 뒷면으로 솟아 격자로(9.2).
5. '열기' 버튼으로도(자동 420ms). 움직임 줄이기면 팩이 사라지고 격자가 나타나는 교차 페이드(300ms).

- **유닛 줄**: `유닛 7/11` + 켜진 유닛 이름을 가는 세로선으로 나눈 글자 목록(가로 스크롤, 알약 칩 금지). 경기장 위에는 켜진 유닛의 카드 사이에 이름표(10px, 바탕 rgba(0,0,0,.5), 모서리 2) — 예 `키스톤` 이 SS–2B 사이.
- 문턱을 넘는 순간: 칸이 왼쪽 → 오른쪽으로 차고(240ms) 줄 전체 흰 막 0 → .2 → 0(300ms) + 게이지가 늘어남.

### 8.6 팀 종합 게이지 (기획서 11절)

- 왼쪽: `팀 종합` 11px `--fg-2` · 큰 숫자 Barlow 800 46px(표시 = 소수점 버림) · 변화 `+7` Barlow 700 18px(`--up`, 1.6초 뒤 흐려짐). classic: Big Shoulders 52px, 초록 점수판 판(`--inv`) 위 흰 페인트 숫자.
- 오른쪽(폭 = 남은 칸): **층별 막대**(높이 10, 모서리 2, 트랙 `--surface-3`): `기본 → 육성 → 팀컬러 → 유닛 → 케미 → 지휘 → 폭발` 순서로 이어 붙인 색 구간.

| 층 | 색(night) |
|---|---|
| 기본(레벨) | `linear-gradient(90deg, #5A6B8C, #B8C3D6)` |
| 육성(강화·스타일·각인) | #DCE3EC |
| 적성 손실 | 막대 끝에서 깎인 만큼 빗금(1px 빨강 45° 결) — 음수라 길이를 줄이는 구간 |

### 8.8 교체

- 카드를 누르면 선택(흰 2px 고리 + translateY −4, 160ms), 들어갈 수 있는 칸 테두리가 흰 30 ↔ 60% 맥박(1.2s), 다른 칸을 누르면 교체(두 카드가 서로 자리로 320ms).
- 길게 눌러 끌기: 카드 scale 1.08 + 그림자 `0 16px 30px -8px rgba(0,0,0,.8)`, 놓으면 가장 가까운 칸으로 220ms.
- **끄는 동안 미리보기**: 놓으면 바뀔 케미 선을 점선 미리 그림 + 팀컬러 줄 숫자 옆 회색 미리값(`19 → 20`, `+6 → +9`) + 게이지 옆 `→ 103` + 켜지는 유닛 이름(기획서 8.6 "이 선수를 넣으면 구단 19 → 20(+6 → +9), 키스톤 켜짐").
- 보관함에서 넣기: 칸을 누르면 아래 시트에 그 칸에 맞는 카드 목록(Row, 정렬 = 넣었을 때 게이지 상승 큰 순, 각 행 오른쪽에 `+1.8`).
- 선택한 카드의 상세는 아래 시트(L 카드 + 이 칸 적성 + 슬롯 OVR 층 내역).

## 9. 뽑기 연출 (기획서 5.10 · 6.11)

### 9.1 원칙

1. **결과는 서버가 먼저 저장했다. 연출은 그 결과를 보여 줄 뿐.** 미리 보이는 빛 신호는 실제 등급과 반드시 같다. 금빛이 났다가 은으로 떨어지는 '거의 될 뻔' 연출 금지.
2. **연출 배급**: 낮은 등급은 짧고 담백하게, 30장 중 **가장 좋은 1장만** 길게(사용자 17·39번).
3. **건너뛰기**: 모든 연출에서 300ms 뒤부터 오른쪽 위 '건너뛰기'(텍스트 버튼, 터치 44×44 이상, 위 = max(52px, 안전영역 + 12px)). 누르면 160ms 교차 페이드로 마지막 상태. 설정 '연출 짧게'(기본 끔).
4. 깜빡임 안전: 1초에 3번 넘게 번쩍이지 않는다. 조명은 점멸이 아니라 페이드로 켜진다.
5. 새로고침·이탈: 결과는 이미 지갑·보관함에 있다. 다시 들어오면 최근 기록(`GET /gacha/history`)으로 요약을 다시 보여 줄 뿐 새로 뽑지 않는다.

### 9.5 여러 팩(1~10팩)

- 팩마다 9.2 의 4~7단계. 한 팩이 끝나면 요약 한 줄(등급별 개수) + **'다음 팩 2/10'**(주 버튼) + '나머지 건너뛰기'(텍스트).
- '나머지 건너뛰기' = 남은 팩 전부 중 **가장 좋은 1장만** 9.4 연출 → 전체 요약(9.7). 300장을 다 뒤집어 보게 하지 않는다.

### 9.6 천장 선택권 · 마일리지

- 선택권 카드를 누르면 시트: 고를 수 있는 카드 격자(S, 그 팩 풀 안의 목표 등급 — 구단팩이면 그 구단). 위에 `레전드 선택권 — 1장을 고르세요`. 고르면 그 카드가 선택권 자리에서 뒤집히며 그 등급의 짧은 연출(레어 조합 길이).
- 마일리지 교환은 확정이라 뽑기 연출이 없다: 선택권 카드가 지갑 쪽으로 미끄러져 들어가는 300ms + 토스트.

### 9.7 결과 요약

- 위: 최고 카드 M(누르면 XL) + 오른쪽에 이름·등급·NEW.
- 등급별 개수 줄: 등급 색 사각 8×8(모서리 1) + 이름 + 개수 — 알약 칩 아님. NEW 개수(볼트 글자), 중복 개수 → `강화 재료로` 설명 한 줄.
- 조합 변화 한 줄(볼트는 이 줄에만): "독수리스 17 → 20명, 구단 +9 단계!" · 천장 막대 · 마일리지 `+270`.
- 버튼: '룰렛으로 보내기'(보조 — 이번에 나온 중복을 미리 골라 둔 룰렛 화면) · **'한 번 더'**(골드, 같은 팩·같은 조합·같은 개수) · '닫기'(텍스트).
- 화면 읽기 프로그램: 요약이 나타날 때 live region 으로 "레어 2장, 엘리트 1장, 새 카드 9장".

### 9.8 소리 큐 (3차 BGM·효과음 담당에게)

팩 흔들림 낮은 울림 · 찢는 소리 · 빛 기둥 '쉬익' · 엠블럼 '쿵' · 포지션 '탁' · 신문 종이 · 응원가 첫 소절(구단별 창작곡) · 공개 차임 · 룰렛 틱 · 강화 각인 '탕' · 능력치 폭발 = 관중 함성 + 큰북. 소리가 꺼져 있어도 **화면만으로 완성**되게.

### 9.9 움직임 줄이기

흔들림·충격파·입자·화면 흔들림·회전 없음. 각 모듈은 opacity 교차 페이드(200)만, 정지 시간은 유지, 뒤집기는 교차 페이드 300. 총 길이 절반 이하.

## 10. 육성 연출

### 10.1 훈련 · 레벨업 · 완성

- XL 카드 아래 경험치 막대(높이 6, 트랙 `--surface-3`, 채움 = 등급 강조색) + `LV 6.40 → 8.12` 숫자 세기(600ms).
- 레벨이 오를 때마다 카드 아래 띠의 핍 하나가 채워지며 '틱'(80ms 흰 막) — 여러 레벨이면 120ms 간격.
- **완성**(최대 레벨 + 경험치 가득): 핍 전체가 왼쪽 → 오른쪽으로 빛남(400) + 카드 위 도장 `완성`(Wanted Sans 900 28, 등급 강조색 테 2px, scale 1.3 → 1, 회전 없음) → 완성 각인 시트(후보 능력치 3개, 기획서 4.4).
- 재료 카드는 대상 카드로 빨려 들어가며 사라짐(각 200ms, 30ms 엇갈림, 화면에 보이는 것은 최대 8장 + `×24`).

### 10.2 강화 (기획서 7.1)

- **+1~+6(100%, 기획서 7.1)**: 재료가 날아들고(10.1과 같음) 강화판에 다음 로마숫자가 도장처럼 새겨짐(scale 1.2 → 1, 200ms) + 대표 6 옆에 `+1` 이 떠오름(+5 는 `+2` + '플레이스타일 열림' 한 줄).
- **+7~+10(확률)**: 화면에 확률을 크게(`75%`, Barlow 800 40) + 아래 보정 막대 3칸(실패 1번마다 1칸, `+15%p`) + "3번 실패하면 다음은 100%".
  - '강화' 버튼 → **결과와 상관없이 똑같은 0.8초** 충전(강화판 테두리를 따라 빛이 한 바퀴) → 결과. 성공·실패에 따라 충전 길이나 모양을 바꾸지 않는다(가짜 긴장 금지).
  - 성공: 강화판 색이 리프랙터 사다리 다음 색으로 바뀌며 빛 한 줄 + `+1 전 능력치`. +10 성공 = 슈퍼프랙터 소용돌이 시작 + 카드 바깥 금빛 띠 + 색종이 40(1.2초).
  - 실패: 강화판 그대로, 카드 30% 어두워졌다 돌아옴(300) + 보정 막대 한 칸 차며 `다음 90%` — **깨짐·금 가는 그림·빨간 화면 없음**(단계가 떨어지지 않으니 잃은 느낌을 주지 않는다).
- 플레이스타일 선택: 후보 카드 4~5장(그 스타일 자세로 다시 그린 초상 + 능력치 변화 `CON +2 · POW −1`), 고르면 카드 그림이 새 자세로 교차 페이드(400).

### 10.3 카드 조합 룰렛 (기획서 7.4)

- 넣은 카드 5~10장이 부채꼴로 펼쳐졌다가 판 가운데로 미끄러져 들어감(각 300, 40 엇갈림).
- **판**: 지름 260 SVG. 칸 = 같은 등급 · 한 단계 위 · 두 단계 위, **칸 각도 = 확률 × 360°**(5장 70·25·5 = 252° · 90° · 18°). 칸 색 = 등급 색(night 는 4.4 테 그라디언트를 칸 안에, classic 은 등급 잉크 망점). 칸 안 글자 = 등급 이름 + `%`(칸이 20° 미만이면 바깥에 지시선). 테두리에 장식 눈금 24개.
- 바늘: 12시 방향 크롬 삼각형(폭 16, 높이 20) + 축.
- 돌리기 3.2초: 0–600 가속(초당 2바퀴까지) → 600–2400 등속 → 2400–3200 감속, 칸 경계와 눈금을 지날 때마다 바늘이 살짝 튕김(±6°, 80ms) + 틱.
- **멈추는 자리 = 결과 칸의 가운데 80% 안에서 고르게**(서버 결과 칸 안, 경계에 아슬아슬하게 걸치는 연출 금지).
- 결과: 판이 사라지고 결과 카드 L 이 뒤집힘. 같은 등급 = 9.3 뒤집기, **윗 등급 = 그 등급 9.4 조합**(사용자 39번 '윗 등급이면 레전드 이펙트').
- 판 아래 한 줄: `레어 70% · 레전드 25% · 엘리트 5% — 서버 난수 · 확률 공개` + '확률 보기'.

### 10.4 시작 지급 · 출석

- 창단 시작 지급: 금액이 계기판처럼 0 → `1조 GP`(넓은 화면은 실제 자릿수) 900ms 굴러감 + 골든볼 `1억` + 강화권 카드 4장이 차례로 미끄러져 들어옴(각 200ms) — 총 1.5초.
- 출석: 큰 연출 없음. '받기'를 누르면 동전 아이콘이 헤더 재화로 날아가며(400) 숫자 세기 + 토스트. 매일 하는 일은 짧게.

## 13. 움직임 · 성능 · 접근성

### 13.1 움직임 토큰 (tokens.css 의 것 + 연출용 추가)

```css
:root {
  --dur-1: 120ms; --dur-2: 220ms; --dur-3: 420ms;          /* 있음 */
  --ease-out: cubic-bezier(.2,.7,.2,1);                     /* 있음 */
  --ease-in-out: cubic-bezier(.6,0,.3,1);                   /* 있음 */
  --ease-snap: cubic-bezier(.3,1.4,.5,1);                   /* 있음 */
  --dur-reveal: 560ms;                                      /* 추가 */
  --ease-enter: cubic-bezier(.05,.7,.1,1);                  /* 추가: 들어올 때 감속 */
  --ease-exit:  cubic-bezier(.3,0,.8,.15);                  /* 추가: 나갈 때 가속 */
  --ease-pop:   cubic-bezier(.34,1.56,.64,1);               /* 추가: 보상 순간에만 */
  --ease-flip:  cubic-bezier(.3,0,.2,1);                    /* 추가: 카드 뒤집기 */

```

들어올 때 감속, 나갈 때 가속, 튀는 것(pop)은 보상 순간에만. 한 화면에서 동시에 크게 움직이는 것은 하나.

### 13.2 휴대폰 성능

- 애니메이션은 `transform`·`opacity`(+ 포일의 `background-position`)만. `box-shadow`·`filter`·`backdrop-filter`·`clip-path` 를 목록에서 움직이지 않는다(홀로·서명 닦기는 카드 1장 상세·공개에서만).
- `mix-blend-mode` 는 화면에 동시에 최대 2장. 격자·목록 카드는 미리 섞은 정지 그림.
- `will-change` 는 직전에 붙이고 끝나면 뗀다. 60장 넘는 목록은 가상 스크롤 + `content-visibility: auto; contain-intrinsic-size: 83px 116px`.
- 입자: 캔버스 1개, 최대 80(보통 48 · 절약 24), 기기 픽셀비 최대 2, 끝나면 멈춤, `document.hidden` 이면 정지.
- 선수 그림 SVG 메모(5.7). L 카드 한 장 DOM 120개 이내. 30장 격자는 초상 30장을 한 번에 그려도 16ms 안(메모 + 초상 단순화).
- **그래픽 품질**: 처음엔 자동 — `navigator.hardwareConcurrency <= 4` 또는 `navigator.deviceMemory <= 4` 또는 `Save-Data` 면 '보통'. 보통 = 반짝임·글레어·입자 줄임, 절약 = 블렌드·반짝임 없음 · 입자 30% · 포일 정지. 설정에서 바꿈.
- 이미지 파일 0개(모두 SVG·CSS). 첫 화면 글꼴 250KB 이하, 카드 목록 JSON 은 화면이 필요할 때 받는다(기획서 20.1).
- 확인: Chrome 성능 패널에서 연출 중 레이아웃·페인트가 없는지, 중간급 휴대폰에서 개봉 연출 60fps.

### 13.3 움직임 줄이기

`@media (prefers-reduced-motion: reduce)` 또는 설정 '항상 줄이기': 크기·이동·회전·흔들림·패럴랙스를 **페이드로 바꾼다**(없애지 않음). 무한 반복(포일 이동·반짝임·형광 숨쉬기·버튼 빛 띠) 정지. 숫자는 세지 않고 바로. 뽑기 9.9, 폭발 8.7 끝, 룰렛 = 결과 칸이 바로 밝아지고 결과 카드 교차 페이드(0.6초).

### 13.4 접근성

- 대비: 본문 4.5:1, 큰 글자(24px 이상 또는 18.66px 굵게) 3:1, UI 부품·의미 있는 그래픽 3:1 — 1.3 · 1.6 · 1.7 · 6.5 값으로 계산 확인.
- 색만으로 정보 전달 금지(1.4). 등급은 영문 등급 이름, 케미는 굵기, 구단은 엠블럼 + 이름.
- 터치 44×44 이상(Mini 카드 + 이름표 = 56×96).
- 카드 `aria-label` 예: "한결찬, 유격수, 엘리트, ’27 대전 독수리스, 카드 OVR 81, 레벨 8.99 / 10, 강화 5단계, 새 카드".
- 번쩍임 1초 3번 이하. 포커스는 늘 보이게(12.2 이중 고리).
- 카드 안 글자는 그림처럼 고정 px, 상세·시트의 같은 정보는 rem 으로 커진다.
