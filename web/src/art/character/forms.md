# 투구·타격 폼 — 변수, 분포, 엔진 효과, 애니메이션

코드: `forms.ts`(변수·분포·이름·효과표) · `motionPitch.ts` · `motionBat.ts` · `motionField.ts` · `rig3.ts`(3D 뼈대) · `live.ts`(움직이는 그림) · `anim.ts`(보간) · `stage.ts`(재생기)
미리보기: 데스크톱 `야구매니저_디자인초안/캐릭터/폼.html` (`?zoom=p3`, `?strip=b2`, `?ev=release`)

범주 값의 키는 `15_선수데이터` 스키마 `forms`/`armSlots` 와 같다(엔진이 그대로 읽음). 그림에 필요한 연속 값은 같은 시드(`선수 id/pitchForm`, `선수 id/batForm`)에서 뽑는다. 범주를 고정하고 싶으면(특별 선수, 코치 훈련으로 폼 변경) `makePitchForm(spec, { armSlot: 'side', … })`.

## 1. 폼 변수

### 투구 (`PitchForm`)

| 변수 | 값 | 그림에서 |
|---|---|---|
| armSlot | over · threeQuarter · side · under | 분류 |
| armAngle | Statcast 식 각도. 90 머리 위, 0 수평, 음수 수평 아래. 분류별 over 73±5 · 3/4 45±6 · side 13±7 · under −24±12 | 릴리스 손 위치(가슴 좌표에서 외전 각 = 90 + armAngle − 몸통 기울기), 몸통 옆 기울기 β = 0.55·(armAngle−15) |
| delivery | windup · set | 와인드업: 홈을 보고 시작 → 로커 스텝 → 축발 돌리기. 세트: 3루 쪽을 보고 멈춤 |
| setHands / overhead | 허리·가슴·턱 / 두 손 머리 위 | 시작 손 높이 |
| legLift / liftH | high · normal · slide / 0..1 | 무릎 높이(허벅지 22°→118°), 들기 시간 |
| tuck | 0..1 | 든 무릎을 2루 쪽으로 감는 정도 |
| hang | 0~0.22초 | 다리 든 채 멈춤 |
| tempo / tempoMul | quick · normal · slow / 0.8~1.3 | 셋업~스트라이드 시간 배율(팔 동작 0.13초는 고정) |

| crossfire / strideZ | 있음·없음 / cm | 디딤발이 몸 앞을 가로지름 |
| hideBall, coil, gloveHigh, armAction | 보통·잘 숨김·보임 / 0..1 / 0..1 / long·short | 몸 비틀기(등번호 보이기), 글러브를 얼굴 앞에, 팔을 짧게 |

| finish / headWhip | balanced · fallOff · hop / 0..1 | 팔로스루 뒷발 착지 위치, 머리 쏠림 |

단계: 셋업(세트·와인드업) → 다리 들기 → (멈춤) → 스트라이드 → 디딤 → 팔 회전(최대 외회전) → 릴리스 → 팔로스루 → 수비 자세.

### 수비·주루 (`motionField.ts`)
포수: 앉은 자세(마스크·보호대) → 포구 → 일어서며 귀 옆에서 옮겨 쥠·잽 스텝 → 2루 송구. 내야: 준비 → 크리프 스텝 2번 → 스플릿 스텝 → 대시 → 땅볼 포구 → 크로우 스텝 송구. 외야: 드롭 스텝 → 뜬공 아래 → 머리 위 캐치 → 크로우 홉 송구. 달리기: 주력 0..1 과 체격으로 속도 6.4~9.4m/s, 발 구름 3.8~4.9보/초, 보폭 = 속도/발 구름(빠른 발 2.0m, 거구 1.5m 안팎), 지면 접촉 비율 20~32%.

## 2. 분포 (시드)

### 팔 각도 — 한국 리그는 옆구리 투수가 흔하다

| 리그 | 오버 | 스리쿼터 | 사이드 | 언더(잠수함) | 옆구리 합 |
|---|---|---|---|---|---|
| KBO (KR·TW 출신 기본) | 18% | 66% | 10% | 6% | **16%** |
| NPB (JP) | 20% | 65% | 11% | 4% | 15% |
| MLB (US·LATAM·AU) | 20% | 73% | 6.5% | 0.5% | 7% |

근거와 추정:
- MLB 는 측정값이 있다. 2008~2015 Brooks 추정 팔 각도로 우투수 1,445명 중 20° 미만(진짜 사이드암)은 21명(1.5%), 20~40°(낮은 스리쿼터)는 183명(12.7%). 좌투는 20° 미만 2.1%. 잠수함(음수 각)은 Tyler Rogers(−59°) 같은 몇 명뿐이다. 그래서 MLB 의 '옆구리'(사이드 + 잠수함)는 낮은 스리쿼터 일부를 합쳐 약 7%로 잡았다. [THT/FanGraphs, Forecasting Pitcher Platoon Splits](https://tht.fangraphs.com/forecasting-pitcher-platoon-splits/) · [MLB.com 팔 각도](https://www.mlb.com/news/the-range-of-pitcher-arm-angles-in-the-2024-mlb-postseason)
- KBO 는 리그 공식 집계를 찾지 못했다. 대신 KBO 기록이 투수를 좌완·우완·**사이드암(언더 포함)** 세 갈래로 나눌 만큼 흔하고([데일리안](https://www.dailian.co.kr/news/view/584139/)), 구단마다 1군 투수 25명 남짓 중 옆구리 투수를 보통 2~4명(선발 1명 안팎 + 불펜) 쓴다 → 8~16%. 게임에서 개성을 보이도록 위쪽 값 16%(사이드 10 + 잠수함 6)를 권장한다.
- `15_선수데이터` 는 사이드 12% + 언더 8% = 20% 로 잡았다. 실제보다 약간 많지만 게임 재미로는 허용 범위. 엔진 생성기와 그림이 같은 값을 쓰도록 둘 중 하나로 맞추면 된다(이 모듈은 `ARM_SLOT_SHARE` 한 곳만 고치면 됨).
- 보정: 좌투는 사이드 ×0.6, 잠수함 ×0.3 (Tim Hill −22° 가 '가장 낮은 좌완'일 만큼 드묾). 키 10cm 클수록 오버 ×1.35, 옆구리 ×0.8.

### 나머지 투구
다리 들기 높게 35 · 보통 50 · 슬라이드 15 / 템포 빠름 30 · 보통 50 · 느림 20 / 공 숨김 보통 70 · 잘 숨김 20 · 보임 10 (스키마와 같음). 크로스 스텝 15%(옆구리 투수 ×1.6). 와인드업 55 · 세트 45(불펜은 세트로 고정 권장). 피니시 균형 52 · 1루 쪽 쏠림 30~40(오버핸드 많음) · 뛰는 피니시 10~18. 보폭은 옆구리일수록 길게(잠수함 +7%p).

### 타격
스탠스 스퀘어 55 · 오픈 30 · 클로즈드 15 / 손 높게 35 · 중간 45 · 낮게 20 / 자세 곧게 35 · 보통 50 · 웅크림 15 / 왜글 없음 50 · 작게 40 · 크게 10 (스키마와 같음). 타이밍 동작은 체격(BMI)과 포지션이 민다: 1루·지명·무거운 타자는 레그킥 최대 ×2, 2루·유격·중견은 토탭 ×1.8 · 노스트라이드 ×1.3. 스윙 궤도 어퍼 32·레벨 50·다운 18(거포는 어퍼 ↑). 한 손 팔로스루 42~57%(거포일수록). 히치 20%, 배트 감기(랩) 15%.

## 4. 애니메이션 구조

- **뼈대**: `rig3.ts` — 골반·가슴 회전(yaw·pitch·roll)으로 척추를 적분하고, 팔·다리는 2관절 IK(팔꿈치·무릎 방향 지정). 손은 가슴 좌표(몸과 함께 돎), 발은 월드 좌표(디딘 발이 미끄러지지 않음), 배트는 굳은 몸(노브 + 방향) — 두 손이 손잡이에 닿게 배트 전체를 당겨 맞춤.
- **카메라**: 투수는 3루 쪽(우투 기준, 홈이 오른쪽), 타자는 홈플레이트 너머(투수가 오른쪽, 12° 돌림), 좌투·좌타는 거울 쌍둥이를 그린 뒤 뒤집고 글자만 다시 바로 세움. 머리는 미리 한 번 그려 목에 붙이므로 얼굴은 언제나 목표(홈·투수)를 본다.
- **보간**: 키프레임 자세를 숫자 45개로 펴서 성분마다 **단조 3차(Fritsch–Carlson)** — 멈춘 키에서 천천히 출발·도착, 같은 방향 구간은 속도를 이어 받음, 넘침이 없어 발이 바닥을 뚫지 않음. 직선 보간 없음. 오버슈트·관성은 키를 더 둬서(무릎 높이 유지 후 낙하, 팔로스루 뒤 반동) 직접 만든다. 팔 휘두름은 실측 시간(디딤→릴리스 0.13초).
- **같은 동작, 다른 사람**: 폼 변수 + 체격(관절 길이·엉덩이 높이 자동 맞춤) + 사람마다 작은 시드 흔들림(각도 ±2~4°, 발 방향) + 외모·유니폼.
- **그리기**: DOM 은 한 번만 만들고 매 프레임 경로 `d`·변환만 바꾼다. 명암은 클립 없이 '법선 안쪽 띠'(외곽을 빛 반대쪽으로 민 곡선)로 2~3단. 빠른 순간만 잔상(팔 = 가는 속도선 3줄, 배트 = 두 겹 부채꼴).
- **성능**: 경로는 0.1cm 정수·상대 좌표(c/s/l)로 써서 숫자→문자열 비용 ¼. 데스크톱 기준 16명 한 프레임 계산 약 5ms(노드 측정). 재생기는 하나의 rAF, 기본 30fps, 화면 밖·숨은 탭 정지, 그리기 예산(7ms)을 넘으면 그림을 돌아가며 나눠 그림(느린 폰은 그림별 fps 만 내려감). `prefers-reduced-motion` 이면 대표 장면 정지.

## 5. 쓰는 법

```ts
const stage = new Stage(); stage.add({ fig, motion, offset: 0, speed: 1, el: svg }); stage.start();
// 경기 화면에서 한 번만: motion.events.release / contact 시각에 맞춰 공·판정 연출
// 카드용 정지 그림: fig.svgFrame(motion.sample(motion.keyTime)).g
```
