# 구단 연도 기록 — `club-seasons.json` 안내

**실제 지역 구단의 그 해 성적**(정규시즌 순위·승무패·포스트시즌·팀 기록)을 구단 코드로 옮긴 자료다. 연도 카드·연도팩·세트덱('그 해 성격')이 이 파일을 쓴다(`clubSeasons.ts` → `sets.ts`). 선수 이름은 없다. 실제 구단 이름과 매핑은 저장소에 두지 않고 작업 폴더 메모에만 있다.

**코드 나누기 (2026-10-23 결정 — '없어진 옛 구단도 전부 따로')**: 현재 구단 10개(DJ·GJ·DG·BS·SB·ST·SH·IC·CW·SW)는 **지금 이름이 된 뒤 연도만** 갖고, 그 앞 시대와 없어진 구단은 옛 구단 코드 10개(DDG·MDH·HBE·SCR·ISB·IJR·IDR·SUC·JDR·IBY)에 따로 있다. 계보(같은 줄 = 이어진 구단, 오래된 순)는 JSON `meta.lineage`: DDG→SB · MDH→GJ · HBE→DJ · SCR→ST · ISB→IJR→IDR→SUC · IBY→IC. 1985 은 시즌 도중 구단이 바뀌어 ISB(전기)·IJR(후기)로 나눴다(승·무·패·순위는 각자 뛴 반기, 팀 기록은 시즌 전체).

> 옛 구단 10개는 `world.ts` 의 `OLD_CLUBS`(가상 이름 · 존재 연도 · 부활 자리)에 있어 `clubSeasons.ts` 가 현재 구단과 같이 읽는다. 옛 코드는 카드 번호처럼 화면에 보일 수 있어 실제 약칭이 드러나지 않는 코드로 바꿨다(2026-10-23, 값은 그대로): DDG 동대문 곰스 · MDH 무등 호랑이즈 · HBE 한밭 독수리스 · SCR 서울 청룡스 · ISB 인천 슈퍼별즈 · IJR 인천 조랑말스 · IDR 인천 돌고래스 · SUC 수원 일각수스 · JDR 전주 돌격대스 · IBY 인천 비룡스.

- 범위: **1982~2026** 시즌 · 만든 날 2026-10-23
- ⚠ 2026 포스트시즌 진행 중 — 한국시리즈(11/2~11/10)가 끝나면 2026 post·titles 갱신 필요
- 우승 연도(1982~2025)는 세 출처(한국어 위키백과·영어 위키백과·나무위키의 한국시리즈 목록)가 **모두 같음**을 확인했다.
- 정규시즌 승·무·패는 나무위키 시즌 문서 · 한국어 위키백과 시즌 문서 · 영어 위키백과 구단 문서를 다수결로 맞췄다. 팀 기록(타율·홈런·평균자책)은 2~4개 출처를 대조했다(아래 '불확실한 값').

## 4. 태그 규칙 (`tagInfo`)

## 8. 다시 만들기 / 갱신

수집·대조 스크립트와 원자료는 저장소 밖 작업 폴더(`scratchpad/clubseasons/`)에 있다: `tools/fetch.py`(robots 판정 포함) → `p_*.py` → `build.py` → `make_md.py` → `verify.py`. 2026 한국시리즈가 끝나면 해당 문서만 다시 받아 `build.py` 의 2026 포스트시즌 줄(P26)을 고치고 다시 돌리면 된다.
